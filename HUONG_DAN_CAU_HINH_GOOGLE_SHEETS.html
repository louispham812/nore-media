Hướng Dẫn Cấu Hình Google Sheets Tự Động

Tài liệu hướng dẫn kết nối Form Website với Google Sheets qua Google Cloud Service Account

1. Mục Đích

Tài liệu này hướng dẫn quý khách hàng các bước thiết lập bảng tính Google Sheets và tài khoản Google Cloud Service Account để website tự động ghi nhận thông tin khách hàng từ form liên hệ/tư vấn.

2. Các Bước Thực Hiện

Bước 1: Tạo Google Sheet và Định Dạng Cột

  1. Truy cập Google Sheets và tạo một bảng tính mới.
  2. Đặt tên file (ví dụ: NORE MEDIA - Khách Hàng).
  3. Đổi tên sheet (tab ở góc dưới cùng bên trái) thành: KhachHang (viết liền, đúng chữ hoa chữ thường).
  4. Tại Dòng 1, nhập tiêu đề các cột theo chuẩn sau:
Cột Tiêu đề cột Mô tả
A Thời gian (UTC) Thời điểm người dùng gửi form
B Họ và tên Họ và tên của khách hàng
C Số điện thoại Số điện thoại liên hệ
D Email Địa chỉ email của khách
E Nội dung tin nhắn Nhu cầu hoặc câu hỏi tư vấn
F Nguồn Mặc định: Website
G Mã gửi form (Submission ID) Bắt buộc: Dùng để kiểm tra chống gửi trùng lặp

Bước 2: Tạo Service Account Trên Google Cloud

  1. Đăng nhập Google Cloud Console.
  2. Tạo một Project mới (ví dụ: Nore Media Form).
  3. Vào ô tìm kiếm trên cùng, gõ Google Sheets API → Nhấp chọn và bấm Enable (Bật).
  4. Vào menu trái: APIs & Services → Credentials → Bấm + CREATE CREDENTIALS → Chọn Service account.
  5. Đặt tên tài khoản (ví dụ: nore-sheets-bot) rồi nhấn Done để hoàn tất.

Bước 3: Lấy File Khóa Bảo Mật (JSON Key)

  1. Tại mục Service Accounts, bấm vào email vừa tạo (có dạng ...@...iam.gserviceaccount.com).
  2. Chuyển sang thẻ KEYS (Khóa) ở thanh trên → Bấm ADD KEY → Create new key.
  3. Chọn loại JSON rồi bấm CREATE.
  4. File .json sẽ tải về máy tính. Mở file bằng Notepad để xem 2 giá trị quan trọng:
    • client_email: Email của tài khoản dịch vụ.
    • private_key: Khóa bảo mật (bắt đầu bằng -----BEGIN PRIVATE KEY-----).

CẢNH BÁO QUAN TRỌNG Ở BƯỚC 4: Nếu không chia sẻ quyền cho email bot, hệ thống sẽ báo lỗi và không thể lưu dữ liệu vào Google Sheet!

Bước 4: Chia Sẻ Quyền Cho Bot Trên Google Sheet

  1. Mở lại file Google Sheet đã tạo ở Bước 1.
  2. Bấm nút Chia sẻ (Share) ở góc trên bên phải.
  3. Dán địa chỉ client_email ở Bước 3 vào ô chia sẻ.
  4. Phân quyền: Người chỉnh sửa (Editor).
  5. Bỏ tích ô "Thông báo cho mọi người" rồi nhấn Chia sẻ (Share).

Bước 5: Lấy Spreadsheet ID

Trên thanh địa chỉ trình duyệt khi đang mở file Google Sheet, link sẽ có dạng:

https://docs.google.com/spreadsheets/d/1a2B3c4D5e6F7g8H9i_xyz/edit#gid=0

Phần chữ và số nằm giữa /d/ và /edit chính là Spreadsheet ID.

3. Template File Cấu Hình (.env)

Quý khách sao chép nội dung bên dưới, điền các thông tin tương ứng và gửi lại cho đội ngũ kỹ thuật:

# ==============================================================================
# CẤU HÌNH GOOGLE SHEETS
# ==============================================================================

# 1. Email Service Account (Lấy từ trường client_email trong file JSON)
GOOGLE_SERVICE_ACCOUNT_EMAIL="nore-sheets-bot@project-name.iam.gserviceaccount.com"

# 2. Khóa Private Key (Lấy từ trường private_key trong file JSON)
# Lưu ý: Giữ nguyên các ký tự \n xuống dòng và bọc trong cặp dấu ngoặc kép ""
GOOGLE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nMIIEvgIBADANBgkqhkiG9w0BAQEFAASCBKgwggSkAgEAAoIBAQD...\n-----END PRIVATE KEY-----\n"

# 3. ID của bảng tính Google Sheet (Lấy từ thanh địa chỉ trình duyệt)
GOOGLE_SHEETS_SPREADSHEET_ID="1a2B3c4D5e6F7g8H9i_xyz"

# 4. Tên tab làm việc trong bảng tính (Mặc định: KhachHang)
GOOGLE_SHEETS_SHEET_NAME="KhachHang"


# ==============================================================================
# CẤU HÌNH GỬI EMAIL THÔNG BÁO (SMTP - NẾU CÓ DÙNG THÊM EMAIL)
# ==============================================================================

# Email nhận thông báo khi có khách đăng ký
CONTACT_EMAIL_TO="admin@noreagency.com"

# Máy chủ SMTP gửi mail (Ví dụ: smtp.gmail.com hoặc máy chủ riêng)
SMTP_HOST="smtp.gmail.com"
SMTP_PORT=465
SMTP_SECURE=true

# Tài khoản email và Mật khẩu ứng dụng (App Password)
SMTP_USER="your-email@gmail.com"
SMTP_PASS="your-app-password"
